# Security

Nuttian's releases here are proofs of concept: do not run them where
security matters.

Still, please tell us about security problems: write to
**security@nuttian.org** (not a public issue). Say which release and
architecture, and how to reproduce the problem.

A problem in Apache NuttX itself also goes to the Apache NuttX project's
security process: <https://nuttx.apache.org/> (Apache Software Foundation
security: security@apache.org). A problem in an upstream program (bash,
OpenSSH, ...) also goes to that project.
